ChronoBudget — Privacy Policy

Last updated: 2026-07-27

Summary

ChronoBudget does not collect, transmit, or share any personal data. There is no account system, no backend server, and no analytics or tracking of any kind. Everything you enter stays on your device.

What data the app stores

All budgeting data you enter — transactions, categories, budget limits, accounts, savings goals, and settings — is stored locally on your device in a private on-device database. This data is never uploaded anywhere and never leaves your device unless you explicitly export it yourself (e.g. the app's built-in CSV export feature, which saves a file using your device's own share/save sheet).

Network access

ChronoBudget makes no network requests. It does not connect to any server, does not use any third-party analytics or advertising SDKs, and does not require an internet connection to function.

Permissions

The app may request access to your device's file system only when you choose to export or import a CSV file — this is used solely to save/read that file and for no other purpose.

Children's privacy

ChronoBudget does not knowingly collect any information from anyone, including children, because it does not collect information at all.

Changes to this policy

If this policy ever changes (for example, if a future version adds an optional cloud sync feature), this page will be updated and the "Last updated" date above will reflect it.
