## Problems encountered

- **`git` not on PATH** in the shell. GitHub Desktop's bundled git could read the remote but could not push (its credential helper needs a `DESKTOP_PORT` that only exists inside GitHub Desktop). Resolved after the user installed standalone Git for Windows (`C:\Program Files\Git\cmd`); pushing works through Git Credential Manager.
- **Placeholder branding.** The app icon, splash and Android icon were unmodified Expo template images; the earlier "store submission readiness" work had covered config but not the artwork.
- **BentoCard amounts truncated at phone width** (found in the first screenshot: "$11…" for $117.00, "$45…" for $450.00). Probe showed the Wants/Savings card text area is only ~92px wide at 430px viewport while `amountFontSize()` allowed 32px up to 9 characters. This is almost certainly the same class of problem the user reported on the S26 Ultra on 2026-09-02. Fixed in `components/BentoCard.tsx`: font size is now `floor(88 / (length × 0.6))` clamped to 16–32. First attempt used 100 and the dev server served a stale bundle (font size still 32); fixed the constant to 88 and restarted Metro with `--clear`, after which the probe showed 20px with no overflow. Not yet checked on a real device.
- **Intermittent CI failure.** `db/__tests__/database.test.ts` › "inserts, updates, deletes, and totals transactions" failed in runs 40 (UTC job) and 42 (Auckland job) but passed locally and in other runs; reproduced locally at roughly 2 failures in 6 runs. Root cause was an app bug, not only a test problem: `fetchRecentTransactions`, `fetchTransactions` (both branches) and `fetchTransfers` used `ORDER BY timestamp DESC` with no tiebreaker, so rows sharing a timestamp tick returned in arbitrary order (the test then updated the wrong row). Fixed with `, id DESC` on all four queries; new "transaction ordering" regression test pins the clock and fails without the fix. 8/8 consecutive full runs then passed (258 tests). This also explains the "one unreproduced parallel-run failure" in the 2026-08-29 Watch note.
- **Repo is public.** An unauthenticated request to `github.com/imad-elia/ChronoBudget` returns 200, while the user said they do not want to share the project. Left for the user to change (Settings → Danger zone → Change visibility). Side effect: free GitHub Pages cannot serve the privacy policy from a private repo, so it would need another host (e.g. Netlify Drop, Cloudflare Pages).
- **EAS CLI is not installed** (not global, not in the project); Node 24.20 and npm 11.19 are present. The project already has the EAS `projectId`.
